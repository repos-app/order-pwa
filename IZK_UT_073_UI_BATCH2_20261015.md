# IZK-UT-073 UI batch 2 — long unbroken display strings

2026-10-15; source-only. Native `mobile-app/web`, production Web `docs/yuwaku`, TEST `docs/yuwaku/test`.

## Scope and cause

Three independent page families: `purchasing.html` supplier directory; `order_items.html` item master; `receipts.html` accounting history. All previously inherited `th,td {white-space:nowrap}`; arbitrary-length escaped supplier names, contact/email, item names, references, method labels and notes could stretch a cell beyond the surrounding scrolling region. In production Web receipts, the table also lacks Native's fixed minimum width. The affected action columns need stable space for edit/delete/reprint/refund. Existing flex supplier heading and purchase-order table protections were preserved.

Changes add scoped CSS on actual rendered `#supRows` / `#rows` cells to wrap text even without natural breakpoints; last-column action controls stay nowrap. Numeric cells and backend records are unchanged. Fallback mail status and refund target wrap independently. No broad `overflow-x:hidden`, ellipsis, substring, or input-value truncation. Original unshortened escaped DOM text is retained; native accessibility obtains the full text from the rendered cell.
